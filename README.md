# Система управління послугами хімчистки

Навчальна практика з розробки та тестування програмного забезпечення.

- **Варіант:** 12
- **Рівень складності:** I (високий, 10–12 балів)
- **Виконав:** Турчак Богдан Богданович, група ІС 23-01

## Опис

Консольний застосунок для працівників хімчистки. Програма дозволяє приймати речі від клієнтів, вибирати для них послуги, розраховувати вартість і строк виконання замовлення та контролювати готовність замовлень. Дані зберігаються в базі даних SQLite, тому не втрачаються після завершення програми.

## Можливості (заплановані)

- [ ] Реєстрація, перегляд, редагування та видалення клієнтів
- [ ] Ведення прайс-листа послуг
- [ ] Оформлення замовлення: речі, матеріал, дефекти, вибір послуг
- [ ] Автоматичний розрахунок вартості (матеріал, терміновість, знижка постійного клієнта)
- [ ] Розрахунок планованої дати готовності
- [ ] Контроль статусів замовлення: Прийнято → В роботі → Готово → Видано / Скасовано
- [ ] Пошук, фільтрація та сортування замовлень
- [ ] Збереження даних у SQLite між запусками

## Вимоги до середовища

- Python 3.10 або новіший
- Сторонні бібліотеки не потрібні: використовуються лише стандартні модулі (`sqlite3`, `unittest`)
